# Test Shkrimi

Sa shpejt shkruan shqip? Mat WPM dhe saktësinë — me histori dhe grafik.

## ✨ Veçoritë

- ⏱️ Zgjedh kohëzgjatjen: 30s / 60s (chips)
- 📝 Tekst shqip i rastësishëm nga 10 fjali të gatshme (~25 fjalë)
- 🟡 Fjala aktuale me highlight gold; shkronjat: ✅ jeshile / ❌ e kuqe me sfond
- ⚡ Live stats: koha, WPM, saktësia % (krahasim char-by-char)
- 🎉 Modal rezultati: WPM i madh, saktësia, karaktere të sakta/gabime + "Provo sërish"
- 📊 Historik në localStorage: lista e testeve (data, WPM, saktësi) + grafik vije + 🏆 "Rekordi yt"
- 🗑️ Fshi historikun (me konfirmim)
